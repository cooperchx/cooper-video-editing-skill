# 验证记录与能力边界

版本 1.1.0，整理日期 2026-10-14。

## 已交付

- 30 个真实 HTML / CSS / JavaScript 动效场景，可在蓝白与黑＋正绿之间切换。
- 60 个场景 GIF，640×360、10 fps，每个 60–80 帧，覆盖完整示例时间段；1 个得意黑动态样张。
- 完整 Skill、机器可读组件清单、视觉参数、字体说明、精剪/字幕/B-roll/声音/蒙版/导出规则。
- 可本地运行的网页、文档生成器、GIF 重建脚本、浏览器与文件检查脚本、依赖锁文件。

## 自动检查内容

`npm run check` 检查组件编号、相对链接、60 个 GIF 的真实多帧结构与尺寸、字体样张、禁止泄露的私人路径/令牌/签名地址。`assets/gif-render-report.json` 记录批量生成的帧数和文件大小。

`npm test` 检查 60 个主题场景组合在入场/停留/后段的执行、字体载入、文本修改、三个数据终值、手机布局和文档的 61 个 GIF。12 组关键画面的倒退重放比较要求 DOM 状态完全一致；浏览器渐变与抗锯齿可能产生少量像素差，视觉比较允许显著差异像素小于 0.1%、平均通道误差小于 0.15/255。实际结果保存在 `assets/browser-qa.json`，并不宣称所有 GPU 都逐像素一致。

Skill YAML 另通过 skill-creator 官方 `quick_validate.py` 检查。网页与仓库发布后再检查公开访问与远端提交一致。

## 人工抽查

对照已确认方向抽看人后编辑卡、背后大字、玻璃卡、多卡、两种椭圆提问、巡游、液体比例和字体样张。确认绿色椭圆中心有填充、字体样张区分清楚、玻璃文字没有整层模糊、卡片巡游使用知识内容。

## 当前不能混淆的边界

- 本库是可复用包装系统与动态演示，不是已经替用户导出一条新成片。
- 人像、界面和 B-roll 示例均为原创代码占位图，不包含用户原素材；连续人物前景、音轨和源时间映射需要在具体项目里处理。
- 公开示例统一使用得意黑；标题、字幕、SVG 数字和匿名素材中的示意文字一起更新。旧字体不再作为当前规范。
- 只有一部分字段提供 UI/API 编辑；子卡标签、图表数据等仍在代码中，需要替换或继续参数化。
- 浏览器的 SVG filter、WebGL、玻璃材质和 CSS 透视，不自动等价于 Remotion 或 ChatCut 的实际导出能力。
- 20–23 为探索备选；三项未来候选效果尚未编码。

## 口播试剪经验

此前已有约 61 秒、16:9 的蓝白口播试剪，包含原生字幕、风格素材、文档展示、流程和总结卡；这说明包装已在口播语义中做过组合尝试。该次工作检查过实际时间线预览，但没有以完整音频复听或最终 MP4 导出作为验收，不能据此声称所有场景已在成片导出通过。本库不公开原工程的私人地址或完整源视频。

下一位 Agent 应在新项目中重复素材、字体、蒙版、时间线与导出检查，不能直接引用历史记录替代本次验证。

## 公开媒体范围

按用户明确选择，公开版以匿名素材发布。`scripts/build-placeholders.cjs` 从零绘制匿名讲述者、虚构界面与两类纹理 SVG，并生成 PNG。全部场景 GIF 重新从匿名版本渲染；原人像轮廓同时换为代码绘图轮廓。原媒体、旧 GIF、私人工作截图以及旧打包文件均不进入 Git 提交。
