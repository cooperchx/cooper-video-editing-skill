# 视觉系统与已确认的边界

## 视觉优先级

用户最新修订 > 已认可的两类人后卡与参考图片 > 本库的示例实现 > 早期 Vox 风格预设。Vox Editorial Explainer 是早期探索，不作为覆盖当前蓝白设计的默认模板。以内容解释、清晰层级和真实素材为主，不使用科技蓝霓虹和强模板感。

## 字体与层级

- 主标题：优先参照用户提供的厚重中文字体图，**准确名称尚未核实**；图片中的 Heavy 1987 不能直接当成已确认的字体名。当前卡片认可外观为研宋，保留其样式参考。
- 二级标题与字幕：用户指定花仿宋，细长宋体、笔画对比明显。它不是普通黑体，不可偷偷替换后称“同款”。
- 公开可运行示例：Noto Serif SC，使用 OFL 字库，明确属于替代。真实项目可接入获授权文件。参考 [字体说明与 GIF](typography.md)。
- 不对已经倾斜的字形重复加斜，不盲目伪粗；英文字母、数字、箭头、中文标点分别检查缺字与基线。

## 形状与材质

1. 人后编辑卡：米白圆角矩形、蓝色编辑选择框、控制点、浅蓝选中条、指针。卡片紧凑，数字和副标题有视觉重量，避免大块空白。
2. 提问卡：圆角外轮廓仍能辨认，边缘轻羽化；内部椭圆是**有完整中心的渐变色块**。文字几何居中后再做视觉校正。蓝绿两版都没有空心洞。
3. 雾面玻璃：错位、反向倾斜、软影、薄边和厚度共同成立。背景可柔化，文字始终清晰。多卡有前后张力，避免平铺等大的呆板排列。
4. 柔光：扩散的无硬轮廓色光。**所有蓝色 3D 球禁止实心硬质纯球体**，绿色版本同样避免突兀装饰球。液体百分比是有数据语义的透明容器，不属于禁用的装饰球。
5. SVG：步骤图使用实心蓝色（随主题变绿）图标；线条服务关系和步骤，不凭空加无意义长线。
6. 大字：左右分组、超大、轻透视和近大远小，插在人物后。只放短词，不遮住整张脸或复制整段字幕。

## 动效语言

以 ease-out 落位、稳定阅读、语义触发为基本节奏。柔光或液面可以细微流动，标题和正文稳定。章节卡有从右侧倾斜飞出到右上方的空间关系；不将普通硬切误称成已实现的转场。

知识卡巡游保留镜头连续性、厚度和软投影。鱼眼只作用于当前卡片中心的内容层，位移向四周平滑归零；卡框、边角和阴影独立绘制，不参与畸变。
